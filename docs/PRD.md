# PRD

## 项目名称

Amanda 离职纪念网站

## 背景

为即将离职的老板 Amanda 制作一个私人的纪念网站，用照片、同事祝福和日签内容，形成一份可长期保存和回看的礼物。

网站不追求商业化展示，而强调温度、回忆感和轻微仪式感。

## 目标

1. 在一个网页中完整呈现纪念内容，便于手机和 iPad 浏览。
2. 支持随机抽取祝福，增强参与感和惊喜感。
3. 支持集中浏览大量照片，并可点击查看大图。
4. 支持一次性浏览全部同事祝福，便于沉浸式阅读。
5. 保持静态站点结构，方便低成本部署到 GitHub Pages。

## 非目标

- 不做后台系统
- 不做用户登录
- 不做在线编辑
- 不做复杂数据库或 CMS
- 不引入前端框架和构建工具，除非未来需求明确升级

## 目标用户

### 主要用户

- Amanda 本人
- 准备礼物的同事

### 次要用户

- 参与送别的团队成员
- 通过链接浏览纪念网站的朋友

## 访问场景

### 手机端

- 通过微信、浏览器或消息链接打开
- 单手快速浏览
- 更关注直观、轻量、情绪到位

### iPad 端

- 更适合停留和细看照片、长文字祝福
- 需要兼顾更舒展的版式和良好的阅读密度

## 核心功能

### 1. 首页整合单页

当前 `index.html` 为最终版主入口，包含全部核心内容分区：

- 封面标题
- 随机漫步
- 照片长廊
- 往昔记忆

目标：

- 用户打开首页后无需在多个页面间跳转，也能看到完整效果
- 支持从首屏快速跳转到不同板块

### 2. 随机漫步

功能说明：

- 点击抽签按钮
- 从 `wishesData` 中随机取出一条内容
- 展示照片、同事祝福和日签
- 在一次循环内尽量避免重复抽到相同内容

展示顺序：

1. 隐藏抽签按钮
2. 显示结果卡片
3. 照片从模糊过渡到清晰
4. 祝福语以打字机形式出现
5. 日签淡入

### 3. 照片长廊

包含两个视觉区：

#### 爱心照片墙

- 用尽可能多的照片拼出爱心轮廓
- 每张照片可点击放大
- 更强调情绪表达和整体视觉识别

#### 原图照片流

- 用原始图片比例展示，不裁切照片主体
- 点击任意照片可进入大图预览
- 更适合完整回看全部素材

### 4. 往昔记忆

- 将全部祝福内容一次性渲染为卡片
- 每张卡片包含一张照片和一段祝福
- 支持移动端与平板端响应式阅读

## 数据需求

### 祝福数据

来源：

- `data/raw/wishes.xlsx`
- `images/wishes/`

字段：

- `id`
- `name`
- `photo`
- `blessing`
- `dailyQuote`

### 照片长廊数据

来源：

- `images/gallery/`

字段：

- `id`
- `photo`
- `title`

## 视觉与设计原则

1. 气质应温暖、克制、文艺，像私人礼物，而不是品牌活动页。
2. 颜色以暖米白、暖棕、金色系为主。
3. 动效要轻，不做过强炫技。
4. 文案阅读必须优先，尤其是长段祝福。
5. 照片展示要尽量尊重原图内容，避免无意义裁切。

## 技术约束

- 纯 HTML / CSS / 原生 JavaScript
- 无构建工具
- 无包管理器
- 无自动化测试
- 页面逻辑依赖 HTML 中脚本加载顺序
- 数据文件 `js/data.js` 必须先于其他业务脚本加载

## 部署方式

### 线上

- GitHub Pages

### 本地

- 直接打开 HTML 文件
- 或通过 Docker + Nginx 本地托管
